# Support

## Para famílias

Precisa de ajuda com o app? Veja as respostas em
[telinhasegura.coding4u.tech/suporte](https://telinhasegura.coding4u.tech/suporte)
ou escreva para suporte@telinhasegura.coding4u.tech. Não mande dados da sua
família nem imagens de crianças.

Achou um vídeo que não deveria estar lá? Denuncie pelo próprio app: a
comunidade revisa de novo.

## For developers

- Bugs and proposals: [open an issue](https://github.com/c4u-tech/c4u-telinhasegura-platform/issues/new/choose).
- Security issues: never in public; see [SECURITY.md](SECURITY.md).
- How to contribute: [CONTRIBUTING.md](CONTRIBUTING.md).
